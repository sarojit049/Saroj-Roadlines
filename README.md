# Saroj Roadlines - Premium B2B Transportation & Logistics Website

Official Phase 1 B2B company website for **Saroj Roadlines** - Reliable Road Transportation & Logistics Solutions.

## Features
- **Company Branding & Credibility**: Clear presentation of Saroj Roadlines without generic AI templates or bloated SaaS components.
- **Fleet Showcase**: Open body and heavy commercial vehicles (19 MT Open Body, 25 MT Open Body, 10-Wheeler, 12-Wheeler).
- **Google Sheets Integration**: Submits partnership & freight enquiries directly to Google Sheets via Google Apps Script Web App.
- **Direct Communication**: One-click Call, WhatsApp (`https://wa.me/917003244983`), and Email (`mailto:sarojroadline@gmail.com`).
- **Dynamic Config**: Centralized contact & GST configuration in `src/config/company.js`.
- **Responsive & Accessible**: Optimized for mobile, tablet, desktop, with support for `@media (prefers-reduced-motion: reduce)`.

## Technology Stack
- React 18+
- Vite
- Lucide React Icons
- Custom Responsive CSS
